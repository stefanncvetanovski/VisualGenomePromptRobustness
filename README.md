# Visual Genome: Отпорно препознавање објекти при манипулативни промптови

## Преглед

Овој проект истражува како манипулативните текстуални промптови влијаат врз визуелното препознавање објекти и дали резултатот од посебно трениран класификатор може да го подобри конечниот одговор на еден визуелно-јазичен модел.

Експериментот поврзува три компоненти:

1. Надгледуван Vision Transformer (ViT), трениран со исечоци од објекти од Visual Genome.
2. CLIP како zero-shot основен модел за споредба.
3. SmolVLM2 како визуелно-јазичен модел што прво добива манипулативен промпт, а потоа и предвидување од ViT како дополнителна информација.

Главното истражувачко прашање е:

> Кога визуелната содржина, манипулативниот промпт и предвидувањето од надворешен класификатор се во конфликт, на која информација најмногу ќе ѝ верува визуелно-јазичниот модел?

## Податочно множество

Во проектот се користат слики и анотации од Visual Genome.

- Слики во оригиналните метаподатоци: 108.077
- Означени објекти во оригиналните анотации: 2.516.939
- Избрани класи: `bicycle`, `bus`, `car`, `cat`, `chair`, `dog`, `horse`, `table`
- Избрани исечоци по класа: 400
- Вкупно исечоци од објекти: 3.200

Подготвеното податочно множество е поделено на следниов начин:

| Множество | Слики по класа | Вкупно слики |
|---|---:|---:|
| Тренирање | 280 | 2.240 |
| Валидација | 60 | 480 |
| Тестирање | 60 | 480 |

Дел од анотациите во Visual Genome се непрецизни или двосмислени. Поради тоа, анализата на грешките содржи и примери кај кои содржината на исечокот не се совпаѓа целосно со ознаката од податочното множество.

## Модели

### Vision Transformer

Надгледуваниот класификатор се заснова на:

```text
google/vit-base-patch16-224-in21k
```

Претходно тренираниот ViT backbone е замрзнат, а неговата класификациска глава е тренирана за осумте избрани класи. Најдобриот модел е зачуван во:

```text
models/vit_visual_genome
```

### CLIP

За zero-shot споредбата се користи:

```text
openai/clip-vit-base-patch32
```

CLIP ја класифицира сликата споредувајќи ја со текстуални описи на осумте класи, без дополнително тренирање со нашето податочно множество.

### SmolVLM2

Во експериментот со влијание на промптови се користи:

```text
HuggingFaceTB/SmolVLM2-2.2B-Instruct
```

За секоја тест-слика, SmolVLM2 последователно добива три промпта:

1. Неутрално барање да го препознае главниот објект.
2. Манипулативно тврдење што бара намерно погрешна класа.
3. Класата и сигурноста предвидени од тренираниот ViT класификатор.

## Резултати

### Надгледуван ViT

- Најдобра валидациска точност: **90,42%**
- Тест-точност: **92,29%**

### CLIP основен модел

- Zero-shot точност: **90,42%**
- Точност при избор меѓу вистинска и случајна погрешна ознака: **97,71%**

### Експеримент со влијание на промптови

Конечниот контролиран експеримент користи 40 тест-слики, односно по 5 слики од секоја класа.

| Фаза | Точни предвидувања | Точност |
|---|---:|---:|
| Неутрален SmolVLM2 | 35/40 | 87,5% |
| По манипулативниот промпт | 13/40 | 32,5% |
| ViT класификатор | 35/40 | 87,5% |
| Конечен интегриран одговор | 37/40 | 92,5% |

Дополнителни метрики:

- Стапка на успешни напади: **65,71%** (`23/35` првично точни примери)
- Стапка на опоравување по додавањето на ViT: **95,65%** (`22/23` успешни напади)
- Конечна согласност со ViT: **90,0%** (`36/40` примери)

Манипулативниот промпт ја намалува точноста од 87,5% на 32,5%. По додавањето на предвидувањето од ViT како дополнителна информација, точноста се зголемува на 92,5%, што е повисоко и од првичниот неутрален резултат.

Визуелно-јазичниот модел не го следи класификаторот слепо. Во неколку случаи го задржува точниот визуелен одговор и покрај погрешно ViT предвидување. Сепак, едно погрешно предвидување од класификаторот предизвикува и погрешен конечен одговор. Ова покажува дека информацијата од класификаторот има големо влијание, но нејзиниот квалитет останува важен.

## Поставување на околината

Проектот е развиен во Ubuntu преку WSL2 и користи NVIDIA графичка картичка преку CUDA.

Креирање и активирање виртуелна околина:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Инсталирање на Python библиотеките:

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

На SmolVLM2 и Triton им се потребни и Linux алатки за компајлирање, како и развојните датотеки за инсталираната Python верзија. За Python 3.14:

```bash
sudo apt install build-essential python3.14-dev unzip
```

## Подготовка на податоците

Датотеките со анотации се чуваат во `data/raw/` и не се додаваат во Git.

```bash
mkdir -p data/raw
wget -P data/raw https://homes.cs.washington.edu/~ranjay/visualgenome/data/dataset/image_data.json.zip
wget -P data/raw https://homes.cs.washington.edu/~ranjay/visualgenome/data/dataset/objects.json.zip
wget -P data/raw https://homes.cs.washington.edu/~ranjay/visualgenome/data/dataset/object_alias.txt
unzip -o data/raw/image_data.json.zip -d data/raw
unzip -o data/raw/objects.json.zip -d data/raw
```

Скриптите за подготовка се извршуваат по следниов редослед:

```bash
python scripts/select_objects.py
python scripts/download_crops.py
python scripts/split_dataset.py
```

## Тренирање и евалуација

Тренирање и евалуација на ViT класификаторот:

```bash
python scripts/train_model.py
python scripts/evaluate_model.py
```

Извршување на CLIP споредбата:

```bash
python scripts/evaluate_clip.py
```

Извршување на контролираниот експеримент со 40 слики и креирање графикони:

```bash
python scripts/evaluate_prompt_attacks.py
python scripts/plot_prompt_results.py
```

## Генерирани резултати

Скриптите ги создаваат следниве датотеки во `outputs/`:

- `confusion_matrix.png` – матрица на конфузија за ViT
- `clip_results.txt` – резултати од CLIP евалуацијата
- `prompt_attack_results.csv` – детални резултати од контролираниот експеримент
- `accuracy_comparison.png` – споредба на точноста пред, за време и по нападот
- `influence_metrics.png` – метрики за нападот, опоравувањето и согласноста со ViT

Големите податоци, тренираните модели, виртуелната околина и генерираните резултати се исклучени од Git преку `.gitignore`.
